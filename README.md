# FoodGuard AI

**FoodGuard AI** is a premium, smart food expiry tracker designed to help you reduce waste and manage your kitchen inventory. It features a modern, dark-themed UI with "Fresh Green" accents and smooth animations.

## Features
- **Dashboard**: Real-time stats on your "Guard Score" and potential waste.
- **Expiry Tracking**: Visual indicators for items expiring soon.
- **Smart Sorting**: Items are automatically sorted by expiry date.
- **Premium UI**: Glassmorphism effects and GSAP-powered animations.

## Setup & Running Locally
1.  Open the `food-guard-ai` folder.
2.  Open `index.html` in your browser.
    - Or run a local server: `npx serve .`

## Deployment (Vercel)
This is a static web application (HTML/CSS/JS), so it can be deployed easily to Vercel.

**Option 1: Drag & Drop**
1.  Go to [vercel.com/new](https://vercel.com/new).
2.  Drag the `food-guard-ai` folder into the import area.
3.  Click **Deploy**.

**Option 2: CLI**
1.  Install Vercel CLI: `npm i -g vercel`
2.  Run `vercel` in this directory.
3.  Follow the prompts.

## Tech Stack
- **HTML5**: Semantic structure.
- **CSS3**: Variables, Flexbox/Grid, Glassmorphism.
- **JavaScript (ES6+)**: Logic and DOM manipulation.
- **GSAP**: Animations.
- **Remix Icons**: Iconography.
